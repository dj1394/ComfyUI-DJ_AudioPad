# ComfyUI-DJ_AudioPad

> 版本 `261016-221551` · 作者：大江

音频加载 + 补齐整数秒节点。在尾部追加静音，把总时长凑成 ceil(原时长) 整数秒——不是截断、不是抹零，是加法补齐。

## ✨ 功能总览

| 项目 | 说明 |
|---|---|
| 节点名 | ComfyUI-DJ_AudioPad_音频补齐整数秒 |
| 输入 | 文件选择下拉（input 目录音频）或上游 AUDIO 连线 |
| 输出 | AUDIO `[1, C, S]` float32 + 时长(秒) FLOAT |
| 核心逻辑 | 尾部追加零值采样，总时长 → ceil(原时长) 整数秒 |
| 硬指标 | 输出时长严格整数秒（浮点误差兜底截断） |

- 原音频内容一字不动，采样率、声道数全部继承原音频
- 支持文件选择下拉 + 上传按钮 + 播放条预览（前端自动提供）
- 上游 AUDIO 输入优先：连了上游节点就用上游的，忽略文件选择
- 缓存指纹：文件用 SHA256，上游连线强制每次重新执行

## 安装

把 `ComfyUI-DJ_AudioPad` 文件夹放进 ComfyUI 的 `custom_nodes\`，重启 ComfyUI。

## 节点参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| audio | 文件下拉 | — | input 目录音频文件，支持上传 |
| audio_input | AUDIO（可选） | — | 上游 AUDIO 连线，优先于文件选择 |

**输出**：`音频` AUDIO tensor `[1, C, S]` float32 + `时长(秒)` FLOAT（精确到小数点后 3 位）。
